# Монитор мест kino.kz

Команда `/kino` открывает inline-клавиатуру с текущими фильмами и кинотеатрами [kino.kz](https://kino.kz/en). Список наблюдения общий для чата: любой участник может включить или выключить фильм и фильтр кинотеатра. `✅` означает, что пункт уже выбран. Если кинотеатры не выбраны, проверяются все кинотеатры настроенного города.

## Компоненты

- `src/kino/client.js` читает публичные каталоги и сеансы через read-only tRPC kino.kz;
- `src/kino/seats.js` ищет последовательные свободные места;
- `src/kino/service.js` строит меню, переключает подписки и запускает проверки;
- `src/worker/index.js` запускает scheduler только в постоянном worker;
- `migrations/006_kino_monitor.sql` создаёт подписки и delivery markers.

По умолчанию используется город Алматы (`KINO_CITY_ID=2`). Каталог меню кешируется в памяти worker на пять минут. Клавиатура разбивается на страницы по восемь пунктов, а выбранные позиции, исчезнувшие из текущей афиши, всё равно показываются, чтобы их можно было удалить.

## Проверка мест

Scheduler запускается сразу при старте worker, затем раз в `KINO_CHECK_INTERVAL_MS` (по умолчанию один час). Он загружает сеансы выбранных фильмов на ближайшие семь дней, исключает прошедшие и, если задан фильтр, чужие кинотеатры. За один tick обрабатывается не более `KINO_MAX_SESSIONS_PER_RUN` подходящих сеансов.

В карте зала свободным считается место со `status=1`. Ряды сортируются по числовому номеру, а при текстовой метке — по координате `y`. Проверяется половина зала с более высокими номерами рядов, включая средний ряд в зале с нечётным числом рядов. Подходящий блок содержит минимум `KINO_ADJACENT_SEATS` последовательных номеров без большого физического разрыва по координатам карты.

Когда блок найден, сервис атомарно вставляет `(chat_id, session_id)` в `kino_notifications`. Поэтому один сеанс оповещается один раз даже при нескольких worker replicas. При временной ошибке Telegram marker удаляется и следующий tick может повторить отправку. Уведомление передаётся общему обработчику `/all`: он проверяет сохранённых участников чата и добавляет безопасные mention entities.

## Доступ к карте зала

Публичные каталоги kino.kz доступны без входа, но текущая страница выбора мест требует пользовательскую сессию. Есть три способа включить проверку мест; если заданы несколько, приоритет имеют tRPC procedure, затем URL-template, затем HTML-страница:

1. `KINO_SESSION_COOKIE` — полная cookie-строка авторизованной сессии kino.kz. Клиент открывает страницу конкретного сеанса и извлекает server-rendered `hall_plan` из Next.js flight payload.
2. `KINO_SEAT_PLAN_URL_TEMPLATE` — актуальный read-only JSON endpoint. Поддерживаются placeholders `{sessionId}`, `{seanceId}`, `{movieId}`, `{cinemaId}`, `{cityId}` и `{input}`. Ответом может быть объект с `hall_plan`, `{data: ...}` или tRPC `{result:{data:{json:...}}}`.
3. `KINO_SEAT_PLAN_PROCEDURE` — имя read-only tRPC procedure на `KINO_BASE_URL`; input имеет вид `{seance_id, city_id, client: "web"}`.

Cookie является секретом: её нельзя коммитить, печатать в логах или передавать клиентам Telegram. После выхода или истечения сессии её нужно обновить. Если не задан ни один способ доступа, `/kino` позволяет подготовить списки, но scheduler не запускается и показывает предупреждение в меню.

## Настройки

| Переменная | Default | Назначение |
| --- | --- | --- |
| `KINO_MONITOR_ENABLED` | `true` | `false` отключает scheduler, не удаляя подписки |
| `KINO_BASE_URL` | `https://kino.kz` | Базовый адрес каталогов и ссылок |
| `KINO_CITY_ID` | `2` | ID города в cookie и API kino.kz |
| `KINO_TIME_ZONE` | `Asia/Almaty` | Локальная дата афиши и отсечение прошедших сеансов |
| `KINO_CHECK_INTERVAL_MS` | `3600000` | Интервал, минимум 60 секунд |
| `KINO_LOOKAHEAD_DAYS` | `7` | Горизонт сеансов, максимум 31 день |
| `KINO_ADJACENT_SEATS` | `2` | Минимальный соседний блок, от 2 до 12 мест |
| `KINO_REQUEST_TIMEOUT_MS` | `15000` | Timeout одного запроса к сайту |
| `KINO_MAX_SESSIONS_PER_RUN` | `300` | Предохранитель числа карт зала за tick |
| `KINO_CATALOG_TTL_MS` | `300000` | In-memory TTL каталогов, минимум 30 секунд |
| `KINO_MENU_PAGE_SIZE` | `8` | Кнопок с пунктами на страницу, максимум 20 |

Интеграция использует внутренние read-only интерфейсы сайта, поэтому изменение kino.kz может потребовать обновления procedure/template или HTML-парсера. Ошибка одного фильма, дня или сеанса логируется и не останавливает остальные проверки.
